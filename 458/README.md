# MSDS 458

This folder contains coursework and experiments for MSDS 458, with an emphasis on deep learning workflows, model comparison, and visualization-heavy notebooks.

## Contents

- `CNN_TSNE/` - CNN and t-SNE assignment notebooks
- `Diamonds/` - Diamonds regression and stack-up work, plus supporting utility scripts
- `Transformer-Based Models/` - Transformer-related assignment material and reference documents
- `Deep Learning with Python, 2nd Edition ...pdf` - reference text used during the course

## Notes

- The folder is organized to keep the assignment deliverables together with the supporting code that produced them.
- The utility scripts in `Diamonds/` are the most reusable source files in this section.
- Folder-level organization is intentionally lightweight so the notebooks remain easy to open directly in GitHub or Jupyter.
