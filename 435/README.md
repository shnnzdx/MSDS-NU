# CIS 435 Portfolio Repository

Cleaned and simplified CIS 435 coursework repository for GitHub.

## Folder Structure

- `notebooks/` - Main Jupyter notebooks (assignments and project work)
- `scripts/` - Python helper scripts
- `datasets/` - Local datasets used by notebooks (kept local; ignored by default)
- `submissions/` - Assignment exports (`.html`, `.pdf`, `.docx`) and final deliverables
- `materials/` - Archived course materials (readings, slides, media, temporary/system files)

## Main Source Code

- `notebooks/*.ipynb`
- `scripts/*.py`

## GitHub Scope (Portfolio-Friendly)

Recommended to commit:
- `notebooks/`
- `scripts/`
- `README.md`
- `.gitignore`
- selected files in `submissions/` (optional)

Recommended to keep out of GitHub:
- `datasets/`
- most of `materials/`
- large media files (`.mp4`, `.m4a`, `.pptx`, `.zip`)

## Notes

- Cleanup was non-destructive: files were reorganized, not deleted.
- Duplicate/temporary items were moved into `materials/` for review before any permanent deletion.
